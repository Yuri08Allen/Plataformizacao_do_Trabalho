# Plataformização do trabalho

Apresentação acadêmica em uma única página rolável, organizada pelos 11 temas do sumário. O conteúdo legível dos slides foi convertido em texto, com a bibliografia reunida uma única vez ao final.

## Abrir

Abra `index.html` no navegador. O sumário no início leva a cada tema; a navegação superior permite voltar ao roteiro e às referências.

## Atualizar

Os trechos marcados “Conteúdo pendente”/“Em desenvolvimento” refletem partes incompletas da apresentação e podem ser editados diretamente no `index.html`. As imagens e os dois vídeos de apoio ficam em `assets/`; clique nas imagens ou em “Ampliar vídeo” para abrir a visualização ampliada.

A página usa as cores creme, marrom e oliva. Open Sauce está configurada como fonte local; se não estiver instalada no dispositivo, o navegador usa uma fonte sem serifa substituta. A tipografia nas imagens originais permanece incorporada nelas.
